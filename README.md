# LUMEN 5.0

LUMEN помогает диспетчеру выбрать, какой участок городской сети проверить первым. В браузере можно разобрать текст жителя, проверить ночной кадр, увидеть изменение маршрута и составить план выездов. Для демонстрации используются 15 модельных участков Тюмени, 10 исходных обращений и 5 учебных кадров. На географическую карту отдельно нанесены четыре реальных ориентира.

## Показ на защите

1. Откройте сайт и нажмите **Репетиция защиты**. Шесть шагов проходят в отдельной демосессии. Завершение, крестик или Esc возвращают рабочие данные.
2. На Цветном бульваре подтвердите пригодный тёмный кадр. Индекс участка изменится с 94 до 84. При одинаковой длине 332 усл. ед. средние индексы двух путей составят 76 и 79.
3. Перейдите в **План смены**. Установите число выездов и зафиксируйте очередь. У каждого выезда можно записать результат осмотра и комментарий. CSV открывается в табличном редакторе.
4. Для свободного показа выйдите из репетиции. В **Диспетчерской** доступны поиск, статусы, история изменений и резервная копия JSON. Копия содержит обращения, решения по кадрам и план. Фотографии остаются на устройстве. Для подтверждения пользовательского кадра после перезагрузки нужно снова открыть тот же файл.

В папке **pitch/** находятся редактируемая презентация PowerPoint, PDF и трёхминутная речь с ответами на вопросы жюри. У слайдов есть заметки докладчика. Ссылки и QR на последнем слайде ведут на прежний адрес демонстрации.

## Netlify

Готовый архив для ручной загрузки называется **LUMEN_5_0_Netlify.zip**. Распакуйте его в отдельную папку. В корне должны лежать index.html, sw.js и _headers. В существующем проекте Netlify откройте **Deploys**, найдите область ручной загрузки и перетащите эту папку. Для сохранения адреса из QR обновляйте проект **warm-florentine-cd885f**. Откройте сайт после успешного деплоя. В заголовке вкладки указано **LUMEN 5.0**. При уже открытой старой версии закройте вкладку и откройте сайт снова.

Для сборки из исходников нужен Python 3.11 или новее. В каталоге с этим README выполните:

```sh
python package_release.py --zip LUMEN_5_0_Netlify.zip
python -m http.server 8000 --directory dist
```

Откройте http://localhost:8000/. При публикации через Git сборка использует netlify.toml и публикует dist/. Для статической демоверсии ключи API и установка npm-пакетов не требуются. После первой полной онлайн-загрузки основной сценарий работает без интернета. Для слоя улиц OpenStreetMap требуется сеть. На вкладке геокарты по умолчанию показана локальная схема по координатам.

## Как устроен прототип

- **Проверка кадра.** Свёрточная сеть из 4 609 параметров оценивает пять классов. Независимая проверка пригодности кадра использует яркость, контраст, пересвет и детализацию. Пригодные тёмные и неравномерно освещённые кадры можно направить человеку. Для засветки требуется пересъёмка. Решение диспетчера и связанная заявка сохраняются вместе.
- **Обращения.** MLP на символьных n-граммах предлагает класс. Приоритет и обработка нерелевантных тем используют правила. После редактирования текста анализ нужно повторить.
- **Маршрут.** Алгоритм Дейкстры сравнивает длину и стоимость пути с поправкой на освещение. Расстояния заданы геометрией учебного графа. Для реальных пешеходных маршрутов потребуются дороги и проверенные полевые данные.
- **План смены.** Модель складывает условный дефицит исходного света (45%), активные заявки (20%), поток (15%), переходы (10%) и погодную нагрузку (10%). Порядок реального обхода задаёт диспетчер. Сохранённый снимок очереди остаётся действующим при последующей смене настроек.
- **Данные.** В статической версии браузер сохраняет рабочие записи в localStorage. Можно переносить рабочее состояние через JSON. Предусмотрен импорт прежних копий обращений и миграция локальной базы LUMEN 4.0 на том же домене. Данные разных устройств разделены.
- **Материалы.** Методика, показатели и ограничения эксперимента приведены в ml/ML_AND_KPI.md. Матрицы ошибок сохранены в ml/exposure_results.json. Фотография и лицензии перечислены на странице credits.html.

## Дополнительный локальный API

Для демонстрации общей базы обращений на одном компьютере доступны FastAPI и SQLite. Из корня проекта:

```sh
python -m pip install -r requirements.txt
python -m uvicorn backend.server:app --host 127.0.0.1 --port 8001
```

При открытии http://127.0.0.1:8001/ верхняя панель показывает «Локальный сервер». Текстовые обращения и история их статусов сохраняются в SQLite. Очередь изображений и план смены остаются в браузере. Сервис предназначен для локальной демонстрации. Городские камеры и сервисы Т2 в прототип не подключены.

## Проверки

```sh
python -m pip install -r requirements-dev.txt
python -m pytest -q
npm install
npm test
python package_release.py --site-only
python -m playwright install chromium
python tests/browser_flow.py
```

Для повторного расчёта испытания CNN установите NumPy и Node.js 18+ и выполните `python ml/exposure_benchmark.py`. Варьируется яркость одних и тех же 400 синтетических сцен. Обучение моделей из исходников требует пакетов из requirements-train.txt. Полевые precision, recall и влияние на работу диспетчера пока не измерены.
